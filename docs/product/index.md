Chaotic Minds Command helps Discord server owners and administrators create a starting structure of roles, categories, and channels. You choose a template, inspect a preview, and explicitly confirm before the app sends changes to Discord.

Use these guides to understand what the app can do today, who can operate it, and what to check before applying a setup. Chaotic Minds Command is an additive setup tool. It does not replace your decisions about role permissions, channel privacy, moderation, or ongoing community management.

  - **[Get started](quickstart.md)** - Follow the first-use workflow from Discord sign-in through a reviewed setup.
  - **[Review a preview](guides/preview-and-review.md)** - Understand every create and reuse item before anything changes in your server.
  - **[For administrators](admins/role-permissions.md)** - Review role permissions and understand channel visibility.
  - **[For server owners](owners/install-the-bot.md)** - Check access, install the bot, and prepare a safe test server.

- **Server members:** Read [what to expect](members/what-to-expect.md) to understand what an administrator's setup may add to your server.

## What Chaotic Minds Command currently provides

Chaotic Minds Command offers Community, Gaming, and Support setup templates. It previews proposed roles and channels, reuses exact matches, creates missing items after confirmation, and provides shared server notes for current server managers.

New roles start with zero permissions and are not assigned to members. Existing roles are reused without changing their permissions. New channels inherit category or server visibility, so an administrator must review access settings separately.
